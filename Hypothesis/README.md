# Probing The Intrinsic Dimensionality Of Learned Visual Representation

Learning visual representation is the core part of computer vision applications. Modern representation are complex and need 
high computing power. Practical scenario demands smaller, efficient representation for efficient computation and inference. 
In mind of this practicality, we propose `"Task-Aligned Intrinsic Dimensionality Hypothesis"` by investigating `STELLAR` backbone
in biological dataset through **Quantification, Investigation and Representation**.
